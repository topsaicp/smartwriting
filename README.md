# 慧策学伴 ScholarFlow · 交互原型

参考 Paperpal 的工作区组织方式，为留学辅导场景设计的独立静态原型。

## 打开

直接打开 `dist/index.html` 即可体验。推荐使用本机服务：

```text
node server.mjs
```

然后访问 `http://127.0.0.1:4186/`。

上传静态服务器时，将 `dist` 内的七个文件放在同一目录即可。

## 可体验的内容

- 写作：编辑、格式修改、预设建议逐条采纳、版本对照、引用插入、Word兼容DOC与TXT导出。
- 课程：三门虚构课程，课程选择、教学节选阅读、翻页和来源定位。
- 复习：计划完成标记、知识卡片翻面、每课程三题短测、评分及解析。
- 辅导：学生回复、老师审核计划和批注，并在对应学生页展示。
- 文献：搜索三篇公开文献元数据、复制APA引用、访问DOI来源。
- 资料导入：本地读取TXT/Markdown（2 MB以内），不发送到服务器。PDF/Word/PPT解析尚未接入。

## 原型边界

“慧策学伴 ScholarFlow”是暂定展示品牌。课程、学生、成绩和辅导过程均为自编示例。AI写作建议和问答采用预设演示，没有实时调用模型。所有编辑、测验、回复、审核和批注仅保存在当前浏览器。

当前未提供真实登录、后台接口、数据库、支付、个性化模型分析、PDF/DOCX解析及原生DOCX导出。角色切换用于体验两种工作区，不代表生产权限控制。当前保留一个活动写作草稿，新建前可以先导出。

三篇文献的作者、标题、年份及DOI已通过Crossref核实；具体论断与原文位置尚需全文核对，详见README-content.txt。

## 源码范围

dist仅含本次新建的7个原型文件（HTML、CSS、JS、SVG）。没有复制原门户或其他既有产品代码；没有用户文件、真实学生记录、账号、API密钥或访问令牌。浏览器演示产生的本地数据不进入源码。外部链接仅指向公开文献DOI页面。
